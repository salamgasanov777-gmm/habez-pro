**Чтобы гарантировать `источник → Habez Pro → AI` без ручной правки AI-базы,**
не хватает трёх звеньев:

1. **Повторяемый перенос №1 → Habez Pro.** Скрипт в репозитории, с прогоном
   без записи, отчётом «было/стало», списком исключений (КОРОЕД 3,5) и
   сравнением значений, а не только количества.
2. **Происхождение в AI-слое.** Сейчас всё записано как один источник.
   Нужна ссылка на документ: письмо, паспорт, этикетку.
3. **Несколько наблюдений одного свойства** (раздел Schema Risks).
