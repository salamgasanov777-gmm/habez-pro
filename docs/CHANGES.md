# Чем эта версия отличается от текущего каталога

Текущий каталог (`HGZ_app`) — статическая PWA: `products.json` и один файл
скриптов на 730 строк. Он хорошо делает ровно одно: показывает характеристики
и считает расход. Всё остальное упирается в то, что у него нет сервера.

| | Каталог сейчас | HGZ Pro |
|---|---|---|
| Данные | файл `products.json`, правится вручную | база, редактор в панели |
| Кто правит | только разработчик | менеджер завода сам |
| Цены | нет | розница, дилер, VIP, объёмные пороги |
| Остатки | нет | есть, видны в карточке |
| Заказ | нет | корзина, оформление, статусы, история |
| Оплата | нет | ЮKassa + демо-режим |
| Заявка на цену | нет | форма с корзиной, попадает менеджеру |
| Клиенты | нет | вход по SMS, кабинет, свои цены |
| Поиск | по названию на клиенте | по названию, ГОСТу и тексту карточки, на сервере |
| Избранное | localStorage, теряется | в аккаунте, на всех устройствах |
| Сравнение | две категории, вшито в код | любые товары, таблица собирается сервером |
| Аналитика | нет | просмотры, продажи, **запросы без результата** |
| Несколько компаний | копировать приложение | одна установка, много компаний |
| Поисковики | одна страница | адрес у каждого товара, разметка Product |

**Что сохранено полностью.** Все 43 товара, 109 таблиц и 688 строк характеристик,
33 калькулятора, подбор по задаче, ГОСТы, фотографии в webp, офлайн-режим,
установка значком на телефон, тёмная тема.

**Что улучшено в самом каталоге.** Поиск теперь находит по тексту инструкции
и по ГОСТу, а не только по названию. Подбор по задаче считается один раз при
загрузке данных, а не перебором на каждое нажатие. Витрина грузится частями:
покупатель не скачивает панель управления. У каждого товара свой адрес — его
можно отправить в WhatsApp, и откроется карточка, а не главная.

**Что стоит перенести в текущий каталог независимо от решения по этой версии.**
Собственный адрес у товара и поиск по тексту карточки — две самые заметные
вещи, и обе делаются в статической версии без сервера.
