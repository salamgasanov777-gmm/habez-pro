# Habez Gips — приложение №2

Читай этот файл первым, если работаешь в этой папке.

## Что это

Каталог продукции Хабезского гипсового завода с сервером, заказами, оплатой
и панелью управления. Сделано 4 сентября 2026.

**Это приложение №2. Оно намеренно не связано с приложением №1.**
Приложение №1 — `~/Desktop/HGZ_app`, сайт `salamgasanov777-gmm.github.io/hgz-catalog`.
Работа над ним идёт отдельно. Ничего из этой папки его затрагивать не должно:
разные репозитории, разные адреса, разные кеши, разные ключи в браузере
(`hgz-*` у первого, `habezpro.*` у второго).

## Как запустить

```bash
cd api && npm install && npm run reset && npm start   # сервер, localhost:4000
cd web && npm install && npm run dev                  # витрина, localhost:5173
```

Панель: `localhost:5173/admin`, вход `admin@habez.local` / `admin12345`.
Тесты: `npm --prefix api test` (должно быть 13 из 13).

## Как обновить сайт

```bash
./deploy.sh            # выгрузить каталог из базы, собрать, залить на Pages
./deploy.sh --prices   # то же самое, но с ценами из базы
```

## Уведомления менеджерам

Новый заказ и заявка уходят push-уведомлением в приложение на телефон
менеджера (карточка «Уведомления о заказах» в сводке панели). Ключи VAPID
создаются сами при первом запуске и лежат в `api/var/vapid.json` — входят
в копию базы. Telegram — дополнительный канал, включается переменными
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, пока не настроен.

На айфоне push работает только у каталога, установленного иконкой.
Заработает по-настоящему после переезда на хостинг: с компьютера владельца
менеджеры до сервера не дотянутся.

## Копии базы

База (`api/var/hgz.db`) в репозиторий не попадает — в ней заказы, заявки
и учётные записи. Копия снимается сама перед каждой выкладкой, лежит в
iCloud Drive, папка «Habez Gips — копии базы», хранятся последние 30.

```bash
./scripts/backup-db.sh                                 копия прямо сейчас
HGZ_BACKUP_DIR=/Volumes/Флешка ./scripts/backup-db.sh   копия в другое место
```

Ежедневное расписание на 20:00 — файл `scripts/ru.habez.hgzpro.backup.plist`,
команда установки в нём же. Владелец ставит его сам: фоновые задания требуют
его подтверждения.

## Правила, которые нельзя нарушать

1. **Цены и остатки не выдумывать.** Настоящих у нас нет. `npm run seed` ставит
   всем товарам «цена по запросу». Демо-цены — только `npm run seed:demo`,
   и на публичный сайт они попадать не должны: `deploy.sh` их вырезает.
2. **Приложение №1 не трогать.** Ни файлы в `~/Desktop/HGZ_app`, ни репозиторий
   `hgz-catalog`, ни его сайт.
3. **Телефон отдела продаж — 8 (928) 032-75-21** (перенесён из приложения №1
   12 сентября 2026, стоит в подвале). **WhatsApp на этом номере нет** —
   владелец подтвердил 12 сентября. Настройка `whatsapp` остаётся пустой,
   заявки с сайта собираются в готовый текст. Не спрашивать повторно.
4. **Ключи, домены и договоры оформляет завод.** ЮKassa, SMS, хостинг —
   до кнопки «оплатить» доводим код, дальше учётные записи владельца.
5. Владелец — не программист. Объяснять обычными словами, команды давать
   целиком, готовыми к копированию. Если можешь сделать сам — делай сам,
   не выдавай список ручных шагов.

## Решения, которые легко случайно откатить

- **Шторка товара на телефоне не меняет адрес.** Открывается через
  `state.sheet` в записи истории, адрес остаётся адресом каталога (как в
  приложении №1). Иначе жест «назад» от края листает «снимки» экранов.
  Переходы из шторки — `replace`. Прямая ссылка `/p/…` — обычная страница.
- **Первый экран** — плитки подбора по задаче и лента «Новое в каталоге»
  (`newArrivals` считает сервер: добавлено после первого дня и не старше
  месяца). Синий блок с цифрами убран по решению владельца 12 сентября.
- **Порядок товаров** выставлен по приложению №1 (`products.position`).
- Сортировка каталога на телефоне скрыта, на компьютере есть.
- В окне QR-кода только код и кнопка «Скопировать ссылку», адреса текстом нет.

## Откуда берутся данные о товарах

Владелец вносит заводские данные в приложение №1 (`~/Desktop/HGZ_app/app/
products.json` и `content.json`). Оттуда они **переносятся сюда по его просьбе**
— читать можно, менять там ничего нельзя. Скрипт переноса пишется под каждый
раз: сверяет карточки по названию, берёт только то, чего у нас меньше.
Короед при переносе **пропускать**: здесь он исправлен на 3,5 мм, а там
остался 2,5.
